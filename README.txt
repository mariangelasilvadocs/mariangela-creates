MARIANGELA CREATES — WEBSITE STARTER
====================================

1. Open index.html in Chrome to preview the website on your computer.
2. To add artwork, save JPG images in the images folder with these exact filenames:
   hero.jpg
   portfolio-1.jpg through portfolio-6.jpg
   book-1.jpg and book-2.jpg
   product-1.jpg through product-3.jpg
   about.jpg
   The placeholders automatically turn into artwork when the matching file exists.
3. Edit text in index.html. Use a plain text/code editor (e.g., VS Code).
4. Change contactEmail in script.js from hello@example.com to your email.
5. To publish for free, create a PUBLIC GitHub repository named
   YOUR-USERNAME.github.io, upload index.html, styles.css, script.js and the
   images folder, and enable GitHub Pages from the main branch if needed.
   The address will be https://YOUR-USERNAME.github.io/.
   We can do this together before connecting your GoDaddy domain.
6. Do not change your domain's nameservers yet. Do not upload passwords or
   private files to a public GitHub repository.
7. The shop is a design preview only; it does NOT process payments or deliver
   downloads. Add a verified checkout provider before offering products for sale.

Note: Fonts are loaded from Google Fonts and require an internet connection;
      fallback fonts will display when offline.
